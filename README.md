# Autograd MLP from Scratch

A compact educational implementation of a **scalar reverse-mode automatic differentiation engine** and a **multi-layer perceptron (MLP) built from scratch in Python**.

The goal of this project is not to use an existing deep-learning framework, but to expose the mechanics behind neural-network training: computational graphs, local derivatives, reverse-mode backpropagation, parameter updates, and loss minimization.

> PyTorch, TensorFlow, and other neural-network libraries are not used to implement the model or backpropagation. Graphviz is used only to visualize computational graphs.

## What is implemented

- A custom scalar `Tensor` class that stores values, gradients, graph parents, and backward functions.
- Differentiable scalar operations:
  - addition and subtraction
  - multiplication and division
  - powers
  - exponential
- Reverse-mode automatic differentiation using topological sorting.
- A differentiable `tanh` activation with gradient accumulation.
- `Neuron`, `Layer`, and `MLP` abstractions built on the custom autograd engine.
- Tanh hidden layers and a linear output layer for regression.
- Mean Squared Error (MSE) implemented with the custom `Tensor` operations.
- A simple gradient-descent optimizer for weights and biases.
- Computational-graph visualization with Graphviz.
- A reproducible regression sanity check with a fixed random seed.

## How the autograd engine works

Each `Tensor` records the values that produced it and a local backward function for the corresponding operation.

Calling `backward()`:

1. Builds a topological ordering of the computational graph.
2. Sets the output gradient to 1.
3. Traverses the graph in reverse topological order.
4. Applies each node's local derivative.
5. Accumulates gradients when a value contributes through multiple downstream paths.

This is the same core idea used by larger automatic-differentiation systems, implemented here at scalar level for clarity.

## Neural-network structure

The notebook builds the network hierarchically:

```text
Tensor
  └── Neuron
        └── Layer
              └── MLP
```

For the final regression demonstration, the model uses:

```text
2 inputs → 2 tanh hidden neurons → 1 linear output
```

The linear output is intentional: unlike `tanh`, it does not constrain a regression prediction to the interval `[-1, 1]`.

## Training demonstration

The final notebook example trains the network on a small deterministic regression sanity check:

- Input: `[1, 3]`
- Target: `2.0`
- Hidden activation: `tanh`
- Output activation: linear
- Loss: Mean Squared Error
- Learning rate: `0.05`
- Epochs: `900`
- Random seed: `42`

Observed output from the executed notebook:

| Epoch | MSE Loss | Prediction |
| ---: | ---: | ---: |
| 0 | 13.17779400 | -1.630123 |
| 100 | 0.00000000 | 2.000000 |
| 899 | 0.00000000 | 2.000000 |

The example is a **sanity check of the implementation**, not a benchmark of predictive performance or generalization. Its purpose is to verify that gradients flow through the custom computational graph and that gradient descent can optimize the network parameters toward the regression target.

## Requirements

The neural-network implementation itself relies mainly on the Python standard library. Graphviz is required only for graph visualization.

Install the Python package:

```bash
pip install graphviz
```

Graphviz also requires the system `dot` executable.

On macOS with Homebrew:

```bash
brew install graphviz
```

Verify the installation with:

```bash
dot -V
```

Then open `MLP.ipynb` in Jupyter Notebook, JupyterLab, or VS Code and run the cells from top to bottom.

## Why this project is "from scratch"

The following components are implemented directly in Python rather than delegated to a machine-learning framework:

- computational-graph construction
- local derivative definitions
- reverse-mode backpropagation
- gradient accumulation
- neurons and fully connected layers
- MLP composition
- MSE loss
- gradient-descent parameter updates

Graphviz is used only for visualization and does not participate in training.

## Scope and limitations

This repository is intentionally small and educational. The autograd engine operates on scalar values rather than vectorized tensors, and the final regression task contains only a small demonstration example. The project is therefore intended to illustrate the mechanics of automatic differentiation and neural-network training rather than provide a production-ready deep-learning framework.
